# Варіант 4 - ТВ-23 Бороденко Роман

**Практична робота 1** - Реалізувати власний аналог функції zip(), що працює з необмеженою кількістю ітераторів.

**Практична робота 2** - Робота з MultiIndex. Створіть багаторівневий індекс і оптимізуйте вибірку за допомогою .xs().

**Практична робота 3** - Використовуючи Numba, реалізуйте обчислення енергетичних інтегралів методом Монте-Карло для прогнозування навантаження на електричну мережу. Порівняйте точність прогнозування енергетичних споживань при різних кількостях ітерацій.

**Практична робота 4** - Реалізуйте байєсівську регресію для моделювання залежностей між погодними умовами та енергоспоживанням. Порівняйте отримані висновки з результатами, отриманими за допомогою класичної лінійної регресії.

**Практична робота 5** - Обробка та злиття даних з різних джерел: Реалізувати обробку даних з CSV, JSON та SQL, їх очищення та злиття в один датафрейм.
